# IMOBJUS - Sistema de Gestao Juridica Imobiliaria

Versao demonstrativa funcional do IMOBJUS, focada nos fluxos imobiliarios juridicos prioritarios:

`login -> dashboard -> pessoas -> imoveis -> locacao -> contratos DOCX -> vistorias/chaves -> encerramento -> manutencao/reparo -> cobranca/inadimplencia -> juridico -> auditoria`.

Esta versao foi sincronizada a partir do arquivo IMOBJUS(4).zip enviado pelo usuario em 05/10/2026.
